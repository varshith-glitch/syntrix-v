# Deep Space Synapse

Build Phase 1 of SYNTRIX based on the attached specification:

Create the multi-page biotechnology operating system shell with the Deep Space Biotech aesthetic (near-black blue/charcoal background, electric cyan, aurora violet, and emerald accents, avoiding generic glassmorphism or cheap neon).

Key Phase 1 deliverables:
1. Application Shell: Collapsible left navigation bar linking to the planned routes, top command bar with system telemetry, and global Command Palette (CMD+K).
2. SYNTRIX Core: The central signature animated 3D/canvas visual object featuring DNA-like structures, neural particles, and orbiting nodes.
3. Backend & Real AI: Enable Lovable Cloud and implement a secure Edge Function for real AI requests so the SYNTRIX Copilot genuinely works, streaming live bioinformatics responses rather than mock text.
4. Foundation routes: Set up the Command Center overview (/command-center) and AI Copilot interface (/copilot) connected to the backend function.
